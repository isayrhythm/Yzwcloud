# Project Memory

- Do not commit or push after every small change. For minor follow-up fixes, edit and verify locally, then report the result and wait for explicit approval before committing or pushing.
- If the user has previously asked for a commit, do not treat that as blanket permission for every later tiny tweak. Batch related changes into a meaningful commit only when the user clearly asks to commit again or approves a proposed commit.
- Pushing to remote should be treated as a separate deliberate step. Ask or wait for explicit direction unless the user specifically requests pushing the current batch.
